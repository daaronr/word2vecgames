# Archive

Superseded material, kept for reference. Nothing here is needed to run the game.

- `legacy-ui/` — the previous server-backed interface (`index.html`, still served
  at `/classic` for the online multiplayer lobby), its backups, the old
  presentation draft (`presentation-v1.html`, was `folder/index.html`), and the
  old start/test scripts.
- `docs/` — earlier planning and deployment notes (Railway, Fly, Render,
  one-click deploys, marketing, copyright, feature write-ups). The live
  deployment is Linode; see `../DEPLOY.md`.
- `deploy-configs/` — config files for hosts we don't use (Railway, Fly.io,
  Render, docker-compose). Move one back to the repo root to use it.
